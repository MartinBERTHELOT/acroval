# Site Acroval Val d'Isère

Site vitrine de l'association Acroval : stages d'oxygénation et d'entraînement (trampoline, gym, tumbling) à Val d'Isère.

- Le site se trouve dans le dossier `site/`.
- Chaque modification poussée sur `main` est mise en ligne automatiquement par GitHub Pages (voir `.github/workflows/deploy.yml`).
